# Loyal Studios Management branding assets

The wrapper is ready for the final approved branding files. No placeholder logo is included so an unapproved visual direction is never presented as final.

Add these files without changing `config.js`:

| File | Recommended export | Used for |
| --- | --- | --- |
| `logo-dark.png` | Transparent PNG, light/white artwork, about 560 × 168 px | Loading screen on dark backgrounds |
| `logo-light.png` | Transparent PNG, dark/black artwork, about 560 × 168 px | Loading screen on light backgrounds |
| `favicon.png` | Square PNG, 48 × 48 px | Browser tab icon |
| `app-icon.png` | Square PNG, 512 × 512 px, with safe padding | Installed app / home-screen icon |

Keep the light and dark logo exports at the same aspect ratio and visual size. Avoid embedding secrets, client data, or Apps Script configuration in any asset metadata.
